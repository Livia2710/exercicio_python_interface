# Exercícios em Python com Interface Gráfica

Repositório privado utilizado para **estudo de Python aplicado a interfaces gráficas**, adaptando exercícios básicos para versões com GUI.

O objetivo é praticar:
- Integração entre lógica e interface
- Organização de código
- Uso de bibliotecas gráficas em Python

## Tecnologias Utilizadas
- Python
- Tkinter / ttkbootstrap (ou similares)

## Conteúdo
- Exercícios básicos com interface gráfica
- Formulários simples
- Interações com botões e inputs
- Testes de layout e usabilidade

## Observações
- Repositório **exclusivamente para estudo**
- Código pode conter versões incompletas ou experimentais
- Não destinado a uso em produção

📌 Repositório mantido privado para fins educacionais.
